- **D2 Select** — Marketplace availability and commission rates cannot be checked automatically (bot blocking). → Humans verify in the lineup until an affiliate API exists; unverified items are marked but not excluded.
- **P2 Source** — Centre-cropping 16:9 to 9:16 pushed the subject out of frame three times. → Every cut is eyeballed on crop-candidate frames (`sources.py`) with a `cx` pan; automatic subject detection is on the backlog.
- **P2 Source** — Source footage's own text (lower-third captions, "Laundry" overlay, a "25,000" graphic, an end-card logo) leaked into reels. → Crop it out with `zoom`+`yoff` or avoid the segment; check filmstrips for text.
- **P3 Render** — A literal `</script>` inside inline JSX closed the script tag early (blank page, no error). → Escape as `<\/script`.
- **P3 Render** — Local font fetches are CORS-blocked under `file://`. → Chrome `--allow-file-access-from-files`; fonts are pinned as local `@font-face` (CDN dynamic subsets change glyphs between frames).
- **P3 Render** — Element screenshots came out 1080×1921 and x264 refused them. → Clip the viewport to exactly 1080×1920.
- **P3 Render** — Template header animations are fixed to absolute seconds (0.05–1.1 s). → Intro narration starts at 0.25 s and stays ≤ 3.5 s.
- **P3 Render** — Estimating subtitle chunk timing from syllable counts was off by ±0.2 s. → Align with Speech-to-Text word offsets (`latest_long`, `▁` tokens).
- **P3 Render** — Mixing the source's own audio (brand music) risks Content ID claims. → Source audio at 0, Lyria BGM only.
- **P3 Render** — Used a TTS 2.5 model and got called out for being outdated. → Re-check the model list at the start of work; currently `gemini-3.1-flash-tts-preview` (3.8 needs a Gemini API key).
- **U1 Publish** — YouTube Data API uploads stay private until the app passes audit; Instagram API allows the tester's own account without review (50/day). → Apply for the audit on day one.
- **Strategy** — Mixing categories breaks profile conversion. → One external identity, lanes as internal keys only; no category lists in the channel description or captions.
- **Strategy** — Brand videos with a 0.02% like rate are paid views. Benchmark only videos with like rate ≥ 0.4%.
