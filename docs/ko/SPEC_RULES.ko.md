# SPEC_RULES — 스펙(대본·템플릿) 작성 규칙

## 1. 템플릿 선택 (`props.layout`)
| 소재 상황 | layout | 비고 |
|---|---|---|
| 출시 당일·가격 공개·사전예약 등 속보 | `breaking` (05) | 티커 4개 = 핵심 숫자 4개 |
| 가격 인하·구형 vs 신형·정가 vs 할인 | `vs` (02) | 쇼핑 태그 직결 |
| 한 제품의 N가지 이유·기능, 제품 N종 묶음 | `list` (04) | points 개수 = bodySubs 청크 개수 |
| 참여·댓글 유도, 가격 맞히기 | `question` (03) | 도입부 ≥ 4초(타이머) |
| 그 외, 충격적 숫자 하나 | `number` (01) | 팩트카드 before→after |
| 신형 vs 구형(경쟁작) 스펙이 2~4줄 | `specs` (06) | rows "항목\|구형\|신형 / …", highlight(가장 큰 변화), badge "+71%" |
| 출시일·사전예약·배송일이 핵심 | `date` (07) | date "10.23", dday "D-6", milestones "발표\|9.9 / 사전예약\|10.16 / 출시\|10.23", progress 0~1 |
| 가격이 커서 체감이 안 될 때 | `convert` (08) | number/unit + equivalents "아이폰 듀오 *3대* / …" (= 환산 칩) |
| 신제품 한 대의 핵심 스탯 3~4개 | `card` (09) | name, tagline, stats "가격\|$1,899 / 화면\|5인치 / …", highlight, price |
| 제품 3~5개를 한 지표로 줄 세울 때 | `rank` (10) | items "이름\|값 / …", unit, unitPos, highlight |
| 발매 정보가 핵심(패션·스니커즈·한정판·굿즈) | `drop` (11) | tag "드롭/발매/한정", name, line1, date, price, where(구매처), colors |
| 두 브랜드·IP 협업 | `collab` (12) | left, right, line1, price, date |
| 컬러·옵션이 볼거리(신발·폰·차) | `colorway` (13) | swatches "이름\|#hex / …" 2~6개(실제 색), name, line1, price |
| 수치 하나가 압도적(마력·배터리·무게·수량) | `stat` (14) | label, number, unit, ring 0~1, sub |
같은 레이아웃 연속 3편 금지. 카테고리 제한 없음(10/18): 패션·신발은 11·13 우선, 협업은 12, 극단 수치는 14. 테마(`props.theme` dark/tint/neon)와 accent 는 make_spec 이 정함 — **회색·어두운 accent 금지(vivid 가드)**. **훅(블러 퀴즈) 인트로는 10/19 폐지** — 각 템플릿이 설계된 인트로로 바로 시작, 인트로 블러 없음.
**정보 형태 → 템플릿 결정 순서**: 날짜가 핵심? → 07 / 비교 대상(구형·경쟁)이 있고 스펙 2줄 이상? → 06 / 가격만 있고 전작 가격도 있음? → 02 / 가격이 크고 환산이 재밌음? → 08 / 제품 여러 개 한 지표? → 10 / 스탯 3~4개 나열? → 09 / 이유·기능 N가지? → 04 / 당일 속보? → 05 / 참여형? → 03 / 그 외 → 01.

## 2. 대본 구조와 길이
훅(숫자) → 정체(브랜드·제품) → 비교(전작·경쟁·사람) → 결론(살 만한가) → 질문.
- **최우선: 중학생이 한 번 듣고 이해**(10/19). 첫 문장 '이게 뭔지', 전문용어·모델명·영어 약어 금지, 한 문장 한 뜻 20자 안팎, 숫자엔 비유, 외화는 '우리 돈 약 N억 원' 환산 필수.
- 훅 ≤ 2.5초, 도입부 ≤ 4초(이게 뭔지 + 정답 숫자), 중반부 14~18초(청크 5개 = 왜 화제/핵심1/핵심2/가격 환산/언제·어디서), 마지막 ≤ 3.5초(질문 1개). 1.1배속 재생, 전체 28~36초 + 엔드카드. 화면 글자도 쉬운 말 8~12자, 한글 단어 중간 줄바꿈 금지(keep-all).
- bodySubs 청크는 나레이션과 **같은 단어**로(STT 정렬용). 청크당 ≤ 14자, `*키워드*` 1개.
- 숫자는 출처가 있는 것만. 스펙 `sources` 배열에 `{"claim": "...", "url": "..."}`. 환율 환산은 "약"과 기준일.
- 금칙: 연예인 이름, 타사 비방, "최고/최초" 단정(출처 없으면), 건강·효능 주장.

## 3. 소스 3개 규칙
메인 뉴스 클립(공식) + 비교/맥락 클립(전작·경쟁·공식) + 사람 나오는 클립. 전부 브랜드 공식 채널 우선. 미디어·크리에이터 영상은 쓰지 않는다.
컷은 장면 경계(도입부/중반부/마지막)에 맞춘다. 각 컷 2~3초, 마지막 컷은 `dur` 생략(장면 나머지 채움).

## 4. 오디오
- TTS: 최신 Google 모델(현재 `gemini-3.1-flash-tts-preview`), 스타일 프롬프트는 레인별 1개 고정, `rate` 1.08.
- BGM: Lyria 3 clip, 프롬프트에 레인 무드 + "Instrumental only, no vocals" + BPM. `bgm_db` -20.
- 원본 현장음 사용 금지.

## 5. 공통 props
`handle` `@channel`, `platform` instagram(유튜브용은 youtube로 2벌), accent는 레인별 기본: AI·IT `#FF5A36`, 골프 `#3D8BFF`, 파워·캠핑 `#FFB21E`, 펫 `#FF4F8B`, AI 로봇 `#3D8BFF`.

## 6. TTS 되읽기 검증 (자동)
모든 나레이션은 합성 후 STT로 되읽어 길이·유사도·숫자를 검사한다(`tts_checked`). 숫자가 3회 연속 누락되면(예: "2,999달러"가 "299"로 들림) **나레이션만 한글 숫자("이천구백구십구 달러")로 바꾼다.** 자막(bodySubs)은 아라비아 숫자 유지.
